While struggling to draw a triangle with wgpu in this project, i got several errors, first of all: buffer layout. When i created the buffer layout for the struct Vertex which is defined as:
pub trait VertexLayout: Sized {
    fn layout() -> wgpu::VertexBufferLayout<'static>;
}
#[repr(C)]
#[derive(Debug, Copy, Clone, bytemuck::Pod, butemuck::Zeroable)]
struct Vertex {
	position:Vec,
	color: Rgba,
	..., inside impl const ATTRIBUTES: [wgpu::VertexAttribute; 2] = vertex_attr_array![0 => Float32x4,1 => Float32x4];
}
impl VertexLayout for Vertex {
    fn layout() -> wgpu::VertexBufferLayout<'static> {
        wgpu::VertexBufferLayout {
            array_stride: std::mem::size_of::<Self>() as wgpu::BufferAddress,
            step_mode: wgpu::VertexStepMode::Vertex,
            attributes: &Self::ATTRIBUTES,
        }
    }
}
where attributes were:
the error was that the first attribute was being understood as a vec4<f32> due to Float32x4 = 4 f32 numbers; while the shader input was the following:
struct Input {
    @location(0) position: vec3<f32>,
    @location(1) color: vec4<f32>
}
in case, its data size would be wrongly passed and so, due to wrong things that happened in the wgpu internals whose i dont know what are, the vertex count would be wrong. Since by the attribute definition it was expecting 8 * sizeof<f32>() and i passed the stride to be sizeof<Self>() where Self = Vertex, it was passing a wrong stride, so the first float of the N + 1 attribute would be understood as the last float of the N attribute.

CCW and back culling.
The default pattern is to draw things with CCW and back culling i saw, but i was attempting to draw the following triangle
let (a,b,c) = (
	Vertex::new(math::Vec3(0.5, -0.5, 0.0), math::Rgba(1.0, 0.0, 1.0, 0.0)),
	Vertex::new(math::Vec3(-0.5, -0.5, 0.0), math::Rgba(1.0, 1.0, 1.0, 1.0)),
	Vertex::new(math::Vec3(0.0, 0.5, 0.0), math::Rgba(0.0, 1.0, 1.0, 1.0)),
);
let vertices = vec![a,b,c];
in case it would be something like
  c
b   a
CCW draws counter clockwise this means that it should draw a to c, c to b and b to a, but it seems to draw by the order, this said, it will draw, a to b, b to c and c to a, but damn, the one i gave is going clockwise, so, as it tried to draw counter clockwise and the one i gave is clockwise, it simply does not draw. be aware of it. One that works is

let (a,b,c) = (
	Vertex::new(math::Vec3(0.5, -0.5, 0.0), math::Rgba(1.0, 0.0, 1.0, 0.0)),
	Vertex::new(math::Vec3(0.0, 0.5, 0.0), math::Rgba(0.0, 1.0, 1.0, 1.0)),
	Vertex::new(math::Vec3(-0.5, -0.5, 0.0), math::Rgba(1.0, 1.0, 1.0, 1.0)),
);
let vertices = vec![a,b,c];

that now can be seen as:

which in fact is counter clockwise
